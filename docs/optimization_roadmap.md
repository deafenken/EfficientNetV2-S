## Completion Route

### Phase 1: Find a stronger transferable family

Run and score A27-A29.

Expected information:

- A27 tells us whether a public distilled SED head transfers.
- A28 tells us whether CNN/OpenVINO image-style inference transfers.
- A29 tells us whether public ensemble logic transfers when all dependencies are mounted under our account.

Decision:

- If one candidate reaches at least 0.93, build the next 3 variants around that family.
- If one candidate reaches at least 0.94, stop broad exploration and focus on calibration/ensembling it.
- If all score below 0.928, do not submit more direct clones.

Result so far: A29 is the new local anchor at 0.929. It is only +0.001 over A0/A24, but it is the first public-code branch that transferred upward. The next work should fork A29, not A27/A28.

### Phase 2: Replace the blocked 0.935 SED heads

The visible 0.935 route depends on private SED weights, so the reproducible path is to replace those heads with public SED alternatives:

- Tucker distilled SED public weights,
- EfficientNet/Perch distill public weights,
- HGNetV2 B0 public inference,
- optional ONNX Perch/dual-SSM as a weak rank stabilizer.

Build A30 as one notebook that computes predictions in the same hidden-test run. Do not ensemble hidden outputs from kernel-source notebooks, because their visible outputs do not contain the hidden test row IDs.

Planned A30:

- Perch/V3 anchor branch,
- best SED branch from A27 or public replacement,
- best CNN branch from A28/A29 if it transfers,
- class-wise rank blend with conservative weights,
- sonotype mirroring from `needless090`,
- no hard threshold unless OOF and public score support it.

### Phase 3: Calibrate, not decorate

If A30 produces a new anchor, fork narrow variants:

| Variant | Purpose |
| --- | --- |
| A31 | Family-wise rank weights: Aves/Amphibia/Insecta/Mammalia/Reptilia |
| A32 | Rare-class shrinkage and score-temperature sweep |
| A33 | Site/hour/window priors with strict clipping |
| A34 | Sonotype/mirror groups only, no other post-processing |
| A35 | Final compact blend of the best two public-scored branches |

Rules:

- Spend no more slots on global threshold toggles.
- Keep each submit as one isolated hypothesis.
- Stop any family after one score below 0.926 unless it supplies a useful component for an ensemble.

### Phase 4: Training route if public transfer stalls

If public code keeps landing below 0.93, leaderboard gap likely comes from trained SED heads, not post-processing. Then the route is:

1. Train or distill a small SED model on competition train audio and public pseudo labels.
2. Cache mel/waveform features in a Kaggle dataset.
3. Build grouped OOF by primary label / recording source.
4. Distill Perch embeddings into a CPU-safe ONNX/TFLite head.
5. Use A0 only as a calibration prior, not as the main predictor.

This is slower but is the real route toward 0.95 if transferable public notebooks are blocked by private weights.
